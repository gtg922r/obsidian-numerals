# Suggestion ownership (Package H2)

One `NumeralsSuggestor` is registered per plugin load. Block and inline settings are checked independently when triggering, returning results and selecting an item. The plugin settings subscription closes existing queries; repeated toggles do not register another instance.

The suggestor consumes G's `getEditorSnapshot` and `subscribeEditorSnapshot` seams. F's index identifies blocks and complete or unfinished inline spans, including their copied physical token ranges. The existing expression scanner excludes string/comment positions. Suggestions do not evaluate math or initialize metadata. Ready snapshot `symbolsAt` supplies successful preceding globals and current locals; only non-calculating contexts supplement eligible ordinary `metadataSymbols`. Original dollar seeds cannot overwrite the current source-order bindings. Pending snapshots may offer built-ins but withhold dynamic symbols.

Each returned item retains its originating query: exact Editor, current vault TFile/path, source ID, index/state identity, settings generation, full source and copied query token offsets. Source/session disappearance, a different state or settings publication retires the query and its subscription. Equal-text source reversions do not restore it. A newly triggered query replaces the previous one; delayed requests and selected items must still match their captured origin. Synchronous property discovery copies own data-property names and declarative opt-in controls without reading unrelated values, invoking accessors/iterators or coercing provider objects, and offers only single-token names supported by reference syntax. The target file identity/path and current allowed property names are rechecked before selection. Current-cache discovery returns an array directly: no obsolete Promise continuation can replace or close a newer native popup.

Explicit selection requires that the same query remains active, the supplied EditorSuggest context still matches and the original cursor is collapsed at the captured token end. It replaces only that token, preserving delimiters, comments and container prefixes; the function caret is placed inside `()`. The source subscription is retired before the edit publishes, and the host popup closes afterwards. Completion does not grant G an independent native-input witness or automatic insertion allowance.

Snapshot/settings changes close obsolete lists rather than inventing a second evaluation or undocumented popup-refresh mechanism. The next trigger reads current data. Existing Reading/Live Preview diagnostics remain shared safely rendered expression-plus-reason text, with reason-aware widget equality. Automated real-class, source and DOM regressions do not establish installed host keyboard or accessibility behavior; Package I owns that acceptance.
